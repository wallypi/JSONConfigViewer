# Changelog

## 0.8.0

- Visual tree and form editor for YAML and JSON.
- Nested object sections with expand/collapse and structure search.
- Inline editing of scalar values and scalar arrays; add/remove array elements.
- JSON Schema auto-detection and manual selection, with form refresh after schema changes.
- Schema-aware labels, descriptions, enums and numeric constraints.
- Multiline text fields, including `x-ui.widget: textarea`.
- YAML comment descriptions and optional inline description display.
- Save/Revert, dirty-state indication and VS Code theme integration.
- Bundled `balanced.yaml` and `balanced.schema.json` examples.
